Remote data sources used by the viewer and bundle:
3D: https://kh.google.com/rt/earth/
2D: https://mt1.google.com/vt?lyrs=s&x={x}&y={y}&z={z}
Both services are operated by Google. Imagery and map data remain the
property of their respective owners. Runtime 3D copyright IDs are resolved
through the service and displayed by the viewer.
These are undocumented endpoints, not a supported public API.

src/vendor/rocktree-decoder.cjs:
Retained from the preceding local Colosseo protocol investigation.
This wrapper contains code derived from a Google web client decoder.
It is not represented as newly authored code or relicensed under MIT here.
Local correction: completed callbacks are deleted using the received message ID.
Protocol reference: https://github.com/retroplasma/earth-reverse-engineering
The reference project and the underlying client code have distinct provenance.

test/fixtures/manifest.json records the original URLs, byte lengths and SHA-256
digests of the three captured protocol fixtures. Binary fixtures are downloaded
locally by scripts/fetch-fixtures.mjs, verified, and excluded from Git.

docs/previews/ contains screenshots of this viewer. Their map imagery and 3D
content retain the same third-party ownership as the live display. Preview
images are documentation, not an independently licensed map-data distribution.

The compiled data API includes the client-derived decoder and has no Three.js
or other rendering-library runtime dependency. The optional compiled demo
includes Three.js 0.180.0, decode-dxt 1.0.1 and three-mesh-bvh 0.9.1.
Their complete MIT license notices are appended to that compiled demo and
copied into licenses/. These notices do not grant additional rights to imagery,
map data or client-derived decoder code. No blanket MIT license is claimed for
this repository.

Build tooling: esbuild 0.28.2; browser validation: playwright-core 1.64.1.
The compiled viewer does not load build tools, Node.js or Playwright at runtime.

Terrain rendering reconstruction:
The selection, request cancellation, transition and shader formulas were
reconstructed from the 20261015_1200_RC02 shipping renderer identified in
docs/reference-client-analysis.md. The original binary and captured source
archives are local investigation inputs, excluded from Git. The numerical
comparison harness requires an explicitly supplied, hash-verified artifact.
See docs/transition-analysis.md and docs/request-cancellation-analysis.md for
function identities, observed settings and verification boundaries.

The terrain atmosphere implementation adapts the active Bruneton scattering functions recovered from the reference client identified in [the source evidence report](docs/reference-client-analysis.md). Only the active terrain call graph is included. The original model carries this license; the optional viewer build retains the notice in its JavaScript output.
