src/vendor/rocktree-decoder.cjs:
Retained from the preceding local Colosseo protocol investigation.
This wrapper contains code derived from a Google web client decoder.
It is not represented as newly authored code or relicensed under MIT here.
Local correction: completed callbacks are deleted using the received message ID.
Protocol reference: https://github.com/retroplasma/earth-reverse-engineering
The reference project and the underlying client code have distinct provenance.

test/fixtures/manifest.json records the original URLs, byte lengths and SHA-256
digests of the three captured protocol fixtures. Binary fixtures are downloaded
locally by scripts/fetch-fixtures.mjs, verified, and excluded from Git.
